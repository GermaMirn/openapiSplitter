# Файлы для тестирования валидации

---------------------------------------------------------------------------
| Файл                         | Ожидаемая ошибка                         |
|------------------------------|------------------------------------------|
| `empty.yaml`                 | Файл пуст                                |
| `whitespace-only.yaml`       | Файл пуст                                |
| `invalid-yaml.yaml`          | Невалидный YAML (незакрытая скобка)      |
| `invalid-yaml-tab.yaml`      | Невалидный YAML (табы вместо пробелов)   |
| `no-openapi.yaml`            | Не OpenAPI: нет поля openapi или swagger |
| `no-info.yaml`               | Не OpenAPI: нет обязательного поля info  |
| `no-paths.yaml`              | Не OpenAPI: нет обязательного поля paths |
| `array-root.yaml`            | Невалидная структура (корень — массив)   |
| `swagger-only-no-paths.yaml` | Не OpenAPI: нет обязательного поля paths |
---------------------------------------------------------------------------
